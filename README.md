🌦 Weather App

 Description

This is a simple weather application built using HTML, CSS, and JavaScript.

It allows users to:

- Search weather by city
- Use current location
- View 5-day forecast
- See recently searched cities
- Get error messages using custom popup


 Project Structure

- index.html → Main UI
- style.css → Styling and responsive design
- script.js → Logic and API calls


 API Used

- OpenWeatherMap API
- URL:
  https://api.openweathermap.org


Database Used

- Browser localStorage (no backend required)



 How to Use

1. Enter a city name and click Search
2. Or click "Use Current Location"
3. Select previous cities from dropdown
4. View current weather and 5-day forecast
